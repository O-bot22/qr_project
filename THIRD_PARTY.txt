actual snapshot used. No current maintenance/security audit is claimed.

Local quirc changes to make the supplied -Wall -Wextra build warning-free:
  quirc.c: cast h to size_t on both sides of one overflow comparison.
  identify.c: explicitly mark area_count's unused y parameter;
  cast two nonnegative comparison operands to unsigned int.
No decoding algorithm changes were intended.

stb_image is compiled with only PNG/JPEG support; no libpng, libjpeg, Java,
Python decoder, or external socket library is used by the executables.
QRDecode is a separate executable invoked by the server via exec.
Test images were generated using Python qrcode and Pillow; running the bundled
tests does not require either library because those image files are included.
